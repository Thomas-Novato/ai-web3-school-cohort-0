## 02｜项目概览：The Agent Economy Live

### 一句话定位

> **AI Agent 的资本市场。** 围观整个 agent 经济，投资你看好的 agent —— Cobo Agentic Wallet 让它偷不走，Vault 让它必须分。

### 解决的核心问题

把真金交给一个自治 AI agent 去经营，如何保证它**不卷款**且**按约分收益**？

| 难点 | 解决方案 | 技术实现 |
|:--|:--|:--|
| Agent 把钱转给自己 | **Cobo Pact（笼子）** | 策略引擎 fail-closed：只允许转白名单地址，越界在签名前被拒 |
| Agent 收钱不分给投资人 | **AgentVault（合约）** | 每笔收入强制按 bps 三方分账；agent 在合约里没有函数能动投资人那份 |
| 投资人凭啥信授权 | **Cobo Owner 审批** | 人类 owner 在 Cobo App 亲手批准 Mandate Pact |

### 双层结构

| 层 | 范围 | 数据源 | 做什么 |
|:--|:--|:--|:--|
| **宏观 Live（舞台）** | 所有 agent | ERC-8004/8183 全网数据（Agent0 subgraph） | 围观、发现、排行、看完整 timeline |
| **可投资层（交易所）** | 上架 + 装 Cobo 钱包的 agent | Cobo Pact / Vault / Market | **投资**（分真实收入） / **下注**（赌表现） / 自动分润 |

### 技术架构（pnpm + Turborepo monorepo）

```
apps/
  web/          Next.js 15 + wagmi/viem + Tailwind v4（Bloomberg 终端风）
packages/
  core/         ERC-8004 Agent0 subgraph 客户端 + 信誉/守约度/综合信任分
  contracts/    AgentVault + Factory + AgentMarket + MockUSDC（Foundry，16 测试）
  cobo/         @cobo/agentic-wallet 封装：笼子 Pact / Mandate Pact / 守约度
  mcp/          MCP server：将 agent 经济暴露给其他 agent
```
