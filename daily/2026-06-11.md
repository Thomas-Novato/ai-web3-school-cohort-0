## 02｜UI 问题排查清单

| 问题类型 | 具体表现 | 预期修复方向 |
|:--|:--|:--|
| **布局适配** | 某些组件在不同屏幕尺寸下出现错位或溢出 | 使用 flex/grid 重构响应式布局，补充 min-width / max-width 约束 |
| **状态反馈** | 数据加载/空状态/错误状态缺乏视觉反馈 | 补充 Loading skeleton、空态提示、错误 Toast 等 UI 状态组件 |
| **交互一致性** | 部分按钮 hover/active/disabled 样式缺失 | 统一设计 token（颜色、阴影、圆角），补充 CSS 伪类状态 |
| **数据联动** | 首页搜索/筛选后下方数据列表未联动更新 | 将搜索词提升为全局状态（React Context 或 zustand），驱动列表过滤 |
| **性能感知** | 数据更新时页面闪动或卡顿 | 引入 React.memo / useMemo 减少不必要的重渲染 |

## 04｜UI 修复路线（按优先级）

1. **P0 — 状态反馈补全**：Loading / Empty / Error 三态，没有这个用户无法判断系统是否在正常工作
2. **P0 — 布局适配**：响应式 breakpoint 修复，确保演示时在不同设备上展示正常
3. **P1 — 搜索联动**：输入 → 结果列表 → 组件状态同步
4. **P1 — 交互一致性**：统一设计 token，补齐悬停/点击/禁用状态
5. **P2 — 性能优化**：大数据量下的渲染优化

---

## 05｜今日收获

> MVP 能跑是一回事，能 **看得舒服、用得顺畅** 是另一回事。UI 打磨阶段需要把对"功能完整性"的注意力转移到"交互体验连贯性"上——每一个加载提示、每一个过渡动画、每一个空状态占位，都是用户在无文档情况下理解产品的线索。
